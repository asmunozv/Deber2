Criterio FEFO

Primero vence, primero sale
Política activa

La reserva prioriza los lotes elegibles con fecha de vencimiento más próxima. Si dos lotes tienen la misma fecha, se utiliza el código de lote como criterio de desempate.

La vista permite consultar la decisión; la asignación y el registro de reservas pertenecen al componente responsable de Inventario.
