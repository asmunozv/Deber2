# Smart Inventory — Diseño de Sistemas (USFQ)

Proyecto de arquitectura para catálogo, inventario por lote/ubicación, reposición y compras, pedidos con FEFO, operación logística de AMR/camiones/muelles, dashboard y analítica.

> **Estado del repositorio:** los artefactos de diseño están redactados y versionados, pero el cierre formal de sprints requiere comprobar en GitHub criterios de aceptación, asignaciones y revisiones. No confundir entrega de archivos con ejecución de ocho semanas de sprints.

## Qué evalúa este deber
Los límites de capacidades y la propiedad exclusiva de los datos; diagramas C4 y UML; interacciones conceptuales recepción → stock → alerta → reposición y reserva FEFO → despacho; al menos cuatro patrones justificados; SOLID con evidencia; requisitos de calidad medibles y trazabilidad de decisiones.

**Fuera de alcance:** contratos técnicos de API y mensajes, pruebas, CI/CD y despliegue. El dashboard es un mockup con información ilustrativa, no una conexión operativa.
